ЛР3 Усложненное 
Цель работы:  
Разобраться в устройстве диффузионных image-to-image моделей.  
Задание:  
1. Выбрать предобученную диффузионную модель (рекомендуется SUPIR) 
2. Изменить процесс сэмплинга модели так, чтобы улучшалась не все изображение, а 
только его фрагмент, заданный маской (SR-inpainting). Маска задается в виде 
бинарного массива с разрешением входного изображения. 
3. Протестировать разработанный алгоритм с разными вариантами маски (полностью 1, 
полностью 0, комбинированная) на нескольких изображениях с различными 
деградациями (например, DIV2K 4x bicubic / unknown / RealESRGAN). 
4. Оценить качество работы с разными вариантами маски с помощью метрик PSNR, 
LPIPS, CLIP-IQA. 
5. Сделать отчёт в виде readme на GitHub, там же должен быть выложен исходный код.  
Отчёт должен содержать следующие пункты:  
1. Теоретическая база  
2. Описание разработанной системы (алгоритмы, принципы работы, архитектура, системные 
требования)  
3. Результаты работы и тестирования системы (скриншоты, изображения, графики, 
закономерности)  
4. Выводы по работе  
5. Использованные источники
